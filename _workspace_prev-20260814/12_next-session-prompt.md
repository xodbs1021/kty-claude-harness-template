## 3. 본 과제 — 회수·레퍼런스 관측 (kty 확정 2026-08-11)

**구조를 새로 만들지 마라 — 관측이 일이다.** kty 가 "회수·조사를 스킬/에이전트로 달아줄까"를
물었고, 직전 세션의 답(kty 수용): 조사 실행은 이미 에이전트(collector/evaluator)이고, 회수의
스킬화는 "선택에 맡기지 않는다" 원칙(README ③)보다 약하며 `ecc:architect`·`planner` 는 Skill
도구 자체가 없다. **관측 결과가 구조를 정한다** — "아예 안 읽는다"가 관측되면 주입 확대,
"읽는데 얕다"면 검수 강화.

**관측 항목 3종** (실제 파이프라인 실행에서 수집 — 하네스가 설치된 프로젝트의 세션 기록·
산출물을 표본으로):

1. **developer 실독 여부** — 프로필 9절 주소(참조용·의무 아님)로 실제로 가는가.
   "이 부분 전에 어떻게 정했더라"가 나온 턴에 진입점 Read 가 있는가
2. **clarifier 표명 준수율** — 질문 전 `사전 결정 회수:` 줄(산문 검증뿐)을 실제로 내는가.
   과거 결정으로 답이 되는 질문이 사용자에게 갔는가
3. **불요 사유 남용** — 레퍼런스 표명의 `불요(<사유>)` 가 인접 도메인을 좁게 자르는 부류
   ("~가 아니라서")인가. 검수(레퍼런스 검증 3항목)가 실제로 그걸 잡았는가

산출: 관측 기록(표본·수치·새는 양상) → 새는 것이 있으면 그때 대응 설계(ADR-0016 후보),
없으면 "관측했고 안 샌다"를 기록하고 닫는다. **관측 없이 의무·구조를 늘리지 마라.**

## 5. 검수 규칙 (이월 — 전문은 SKILL.md 듀얼 리뷰 절)

- 모든 검수 게이트는 Claude + codex **듀얼 병렬 독립.** codex 는 `gpt-5.6-sol` + `effort high`
  고정(훅 차단) · `< /dev/null` · git 저장소 안 · 출력 파일 · "정적 독해·판정 줄" 명시
- **⚠ 실행형 검수와 정적 검수를 같은 트리에서 병렬로 돌리지 마라** (직전 세션 실측 —
  ecc:code-reviewer 가 변이 하네스를 실측 실행하는 동안 codex 가 같은 트리를 읽어 변이 주입
  순간을 "잔류 결함 HIGH"로 오인). 순차로 돌리거나, 정적 검수 프롬프트에 커밋 해시를 명시해
  검증 시점을 고정하라
- 리뷰 산출물 파일명에 `00_design`·`01_plan` 접두어 금지
- 완료 대기: macOS 에 `timeout` 없음 — `seq` 폴링 루프 또는 Monitor
- 비수렴 기준 착수 시 못박기: ①수정마다 새 차단급 ②결함 폭 좁아짐 — 함께면 성격으로 갈라 닫기
- **차단급 = CRITICAL/HIGH 만이다.** 직전 세션이 MEDIUM 을 섞어 세었다가 pr-reviewer 에게
  잡혔다(15→9 정정). 보고 숫자는 집계 기준을 괄호로 명시하라
- 검수 대기 중 통합 기록에 결과를 미리 적지 마라 — "(진행 예정)"으로 두고 실측 후 기록

## 6. 직전 세션이 당한·피한 함정 (실측)

1. **병렬 측정 오염** (5절 ⚠ — 새 함정. 이번 인계의 최대 교훈)
2. **설계 산출물 자신이 게이트 대상이다** — 설계서 둘째 줄 표명을 처음부터 지켜라. 직전
   세션 설계서의 `불요` 사유가 검수 항목("인접 도메인을 좁게 잘라 불요") 위반 실례로 적발돼
   `조사함`으로 뒤집혔다 — 자기 사유부터 그 기준으로 심사하라
3. **한 줄 관용구를 자리만 옮기면 no-op 이 된다** — `read || [ -n ]` 는 while 조건에서만
   방어였다. 단발 read 에선 rc 를 소비하는 분기가 필요했다(검수가 적발). 관용구를 복사할 때
   **rc 를 누가 소비하는지** 확인하라
4. **앵커 기반 변이는 대상 텍스트 개편에 깨진다** — m10·m15 가 0회 매치 위기(설계 검수가
   사전 적발). 게이트 텍스트를 고치면 변이 하네스 앵커를 전수 재검증하라(fail-closed 라
   조용히 새지는 않지만 측정이 죽는다)
5. `git add -A` 금지 — 명시 경로 add. `.err` 대용량 잔여물이 실제로 생겼다(.gitignore 가 걸렀다)
6. 훅 비활성 문자열은 Bash 히어독 금지 — Write 도구 + `--body-file` (문서화된 경로)
7. Fact-Forcing Gate 는 파일마다 첫 편집에서 막는다 — 사실 4종 제시 후 재시도. 끄지 마라
